# Formato de cada arquivo de `contexto/`

Templates dos 8 arquivos que o Passaporte gera. Use estes como esqueleto — preencha com as
palavras DELA, sem traduzir pra "linguagem profissional".

---

## `contexto/01-empresa.md`

```markdown
# Empresa

## Nome
[Nome oficial da empresa] · marca [Nome da marca pessoal, se diferente]

## Posicionamento em uma frase
[Frase única, na voz dela. Ex: "A mentoria que ensina mulheres exigentes a fazerem do
Instagram um ativo, e não uma corrida."]

## Nicho específico
[Detalhar — não só "marketing", mas "marketing pra advogadas de família, terapeutas de
casal, consultoras premium"]

## Tese de mercado
[O que ela defende que outros não defendem. Frase única. Ex: "Postar todo dia funciona,
mas precisa de método."]

## Concorrentes diretos
- [Nome 1] — [como difere]
- [Nome 2] — [como difere]
- [Nome 3] — [como difere]

## Tempo no mercado
[Quanto tempo nesse posicionamento — ex: "3 anos com Castle, 6 meses com CCC"]

## Fundadora
[Nome] — [breve descrição em 1 frase]
```

## NOTAS GERAIS

- **Sempre usar markdown limpo.** Skills downstream parseiam por estrutura.
- **Sempre incluir trechos textuais** (frases, depoimentos, mensagens). Skills de criação
  usam isso pra calibrar voz.
- **Quando algo não foi capturado, registrar como gap.** Use:
  ```
  > [ ] Pendente: [o que falta]
  ```
- **Versionamento.** Adicione no final de cada arquivo:
  ```
  ---
  Última atualização: [DATA]
  Próxima revisão sugerida: [+3 meses]
  ```
