# Templates de roteiro por duração

Esqueletos de timing concretos. Use como base — sempre adaptando à voz da
`02-voz-e-tom.md`.

> **Regra de palavras por segundo:** fala calma = 2.5 ppl/s, ritmo médio = 3 ppl/s,
> ritmo acelerado = 3.5 ppl/s. Acima disso vira frenético.

---

## ESTRUTURA 15s — Snappy

**Funções viáveis:** Atrair, raramente Posicionar.
**Total de palavras:** 38-50

| Tempo | Beat | Palavras max |
|---|---|---|
| 0-3s | Hook | 8-10 |
| 3-12s | Desenvolvimento — 2-3 pontos rápidos | 25-30 |
| 12-15s | CTA curto | 6-10 |

**Template:**

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Hook punchy — frase única, ~3s falada]"
**VISUAL:** [Plano fechado / cena impactante]
**TEXTO NA TELA:** [Frase-âncora em CAPS]

## ATO 2 — DESENVOLVIMENTO (3-12s)
| Tempo | Fala | Visual | Texto na tela |
|---|---|---|---|
| 3-6s | "[ponto 1]" | [corte 1] | "1." |
| 6-9s | "[ponto 2]" | [corte 2] | "2." |
| 9-12s | "[ponto 3]" | [corte 3] | "3." |

## ATO 3 — CTA (12-15s)
**FALA:** "[CTA específico, 1 frase]"
**VISUAL:** [ela apontando / arrow / produto]
**TEXTO:** [CTA reforçado]
```

## ESTRUTURA 30s — Padrão

**Funções viáveis:** Todas (padrão).
**Total de palavras:** 75-105

### Variante POSICIONAR (30s)

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Tese provocativa em 1 frase, 8-10 palavras]"
**VISUAL:** [Olhar direto, corte fechado no rosto]

## ATO 2 — DESENVOLVIMENTO (3-22s)
| Tempo | Fala | Visual |
|---|---|---|
| 3-7s | "[Setup — leitura comum]" | [Plano médio] |
| 7-12s | "[Reframe — a virada]" | [Aproximação] |
| 12-17s | "[Aplicação ao leitor]" | [Plano frontal direto] |
| 17-22s | "[Frase-âncora — quote tatuável]" | [Plano fechado, pausa dramática] |

## ATO 3 — CTA (22-30s)
**FALA:** "[CTA editorial — não venda]"
**VISUAL:** [Plano aberto, ela em movimento OU sentada calma]
```

### Variante ATRAIR (30s)

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Listicle teaser — 5 erros, o quarto te custa cliente]"
**VISUAL:** [Energia alta, corte rápido]
**TEXTO:** "5 ERROS"

## ATO 2 — DESENVOLVIMENTO (3-26s)
| Tempo | Fala | Visual | Texto |
|---|---|---|---|
| 3-7s | "Erro 1: [erro]" | [b-roll] | "1" |
| 7-12s | "Erro 2: [erro]" | [b-roll] | "2" |
| 12-17s | "Erro 3: [erro]" | [b-roll] | "3" |
| 17-22s | "Erro 4 — o que mais custa: [erro]" | [destaque] | "4 ⚠️" |
| 22-26s | "Erro 5: [erro]" | [b-roll] | "5" |

## ATO 3 — CTA (26-30s)
**FALA:** "[Pergunta engajamento + lead magnet]"
**TEXTO:** "[link/comando]"
```

### Variante Conversão (30s)

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Promessa específica + prazo]"
**TEXTO:** [Nome da oferta + lote/prazo em CAPS]

## ATO 2 — DESENVOLVIMENTO (3-25s)
| Tempo | Fala | Visual |
|---|---|---|
| 3-7s | "[Dor reconhecida — frase real do cliente]" | [Aproximação] |
| 7-12s | "[O que é a oferta]" | [Mostra material] |
| 12-17s | "[Como funciona — 3 etapas]" | [B-roll método] |
| 17-22s | "[Prova social — depoimento curto]" | [Quote/foto cliente] |
| 22-25s | "[Quebra-objeção principal]" | [Volta pra ela] |

## ATO 3 — CTA (25-30s)
**FALA:** "[Comenta CCC + escassez factual]"
**TEXTO:** "CCC → DM" + "Lote fecha [data]"
```

### Variante RECONECTAR (30s — desafio, prefira 60s)

> ⚠️ Reconectar em 30s corta o arco. Use só se a história é minimalista
> ("uma frase muda tudo"). Pra storytelling completo, recomendar 45-60s.

## ESTRUTURA 60s — Storytelling padrão

**Funções viáveis:** Reconectar (padrão), Conversão (com prova social longa).
**Total de palavras:** 150-210

### Variante RECONECTAR (60s)

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Confissão crua — 'eu também já...' / 'demorei X anos pra...']"
**VISUAL:** [Plano íntimo, fechado no rosto, luz suave]

## ATO 2 — DESENVOLVIMENTO (3-50s)
| Tempo | Beat | Conteúdo |
|---|---|---|
| 3-12s | Setup do contexto | "Eu vivia [situação]. Achava que [crença antiga]." |
| 12-25s | A virada | "Foi quando [evento gatilho]. E eu entendi que [insight]." |
| 25-35s | Aprofundamento | Detalhe concreto da virada |
| 35-45s | Lição extraída | "O que aprendi foi..." |
| 45-50s | Como aplico hoje | "Hoje eu [ação]" |

## ATO 3 — CTA (50-60s)
**FALA:** "[CTA suave — 'me conta no DM' / pergunta reflexiva]"
**VISUAL:** [Plano aberto, ela em silêncio nos últimos 2s]
```

### Variante Conversão (60s — com prova social desenvolvida)

```markdown
## ATO 1 — HOOK (0-3s)
**FALA:** "[Promessa + prazo]"

## ATO 2 — DESENVOLVIMENTO (3-50s)
| Tempo | Beat | Conteúdo |
|---|---|---|
| 3-8s | Dor reconhecida | Frase real do cliente |
| 8-14s | O que é | Nome + formato |
| 14-22s | Como funciona | 3 etapas (Diagnóstico → Fundação → Operação) |
| 22-32s | Prova social 1 | Cliente A com depoimento |
| 32-40s | Prova social 2 | Cliente B com depoimento (opcional) |
| 40-46s | Quebra-objeção | "Você pode pensar X. Mas Y." |
| 46-50s | Escassez factual | Lote + prazo |

## ATO 3 — CTA (50-60s)
**FALA:** "[Comenta CCC, mando link]"
**VISUAL:** [Material da oferta na tela]
```

## ESTRUTURA 90s — Storytelling longo

**Funções viáveis:** Reconectar profundo, Conversão de alto-ticket (Castle).
**Total de palavras:** 220-310

> ⚠️ Reels de 90s exigem retenção excepcional. Só usar se:
> - Audiência muito quente
> - História genuinamente densa
> - Oferta de alto-ticket onde decisão demanda contexto

```markdown
## ATO 1 — HOOK (0-4s)
**FALA:** "[Hook + promessa de história]"

## ATO 2 — DESENVOLVIMENTO (4-78s)
| Tempo | Beat |
|---|---|
| 4-15s | Setup vasto |
| 15-30s | Primeira virada |
| 30-50s | Aprofundamento + tensão |
| 50-65s | Segunda virada / lição |
| 65-78s | Aplicação concreta |

## ATO 3 — CTA (78-90s)
**FALA:** "[CTA com tempo pra desenvolver — agendamento, aplicação, mentoria]"
```

## REGRAS DE FORMATAÇÃO DO ROTEIRO

1. **Falas em aspas** — sempre entre aspas tipográficas " " pra distinguir do resto
2. **Visual em colchetes** — [colchetes] indicam descrição de cena, não fala
3. **Texto na tela em CAPS** — quando o overlay é texto, escrever em CAPS pra
   diferenciar visualmente
4. **Palavras-chave em negrito** dentro da fala — pra a aluna saber onde dar peso
5. **Pausas marcadas com (...)** — quando há pausa intencional dentro de uma fala

Exemplo:

```
**FALA:** "Premium não é preço. (...) É tese."
**TEXTO NA TELA:** "PREMIUM ≠ PREÇO"
**VISUAL:** [Plano frontal, ela faz pausa de 0.5s entre as duas frases]
```

## VERSÃO TELEPROMPTER

Pra cada roteiro, sempre gerar arquivo separado `teleprompter.md` com:

- Apenas as falas, em ordem
- Fonte simples e grande quando lida no celular
- Sem direções de cena, sem textos na tela
- Marcação de pausa com `///` entre frases-âncora

Exemplo:

```
[FALA 1]
Premium não é preço.

///

[FALA 2]
É tese.

///

[FALA 3]
Quem confunde os dois fica refém do desconto pra sempre.

[...]
```

Isso facilita gravação — ela cola num teleprompter ou abre no celular.
